# خطة إكمال SOUQNA

## الوضع الحالي
المشروع نسخة React/Vite تعمل كواجهة Demo مع خادم Express محدود وتخزين محلي. سنحافظ على البنية الحالية في هذه المرحلة بدل تحويل شامل إلى Next.js، مع فصل الخدمات الحساسة وإضافة عقود Backend قابلة للربط بـ Supabase عند توفير الإعدادات.

## التنفيذ الحالي
- تصحيح الهوية إلى سوقنا / SOUQNA وإزالة اسم سوقنا من metadata وSEO.
- تصحيح الخطط إلى Free/Pro/Business والأسعار والحدود الواردة في المتطلبات.
- إضافة مسارات URL حقيقية عبر history fallback وواجهة route state متوافقة مع المشروع الحالي.
- نقل إنشاء الدفع إلى Backend فقط، مع عقد Karam Pay المؤكد: `POST /api/payments`، `Idempotency-Key`، `checkout_url`، و`GET /api/payments/{payment_id}`.
- إضافة endpoints داخل مشروع SOUQNA لإنشاء عملية خدمة مدفوعة، فحص الحالة، وWebhook داخلي قابل للتوقيع عند تزويد عقد Karam Pay الرسمي للـ webhook.
- منع تفعيل الخدمة من صفحة العودة وحدها، وتسجيل حالة الدفع والأحداث مع idempotency في طبقة الخادم.
- توسيع مخطط Supabase للمتاجر والمنتجات والطلبات والخطط والاشتراكات والمدفوعات وسجل الأحداث والصلاحيات الأساسية.
- إضافة route manifest، وتحديث `.env.example` بالأسماء المطلوبة دون أسرار.

## ما يحتاج إعدادًا خارجيًا قبل الإنتاج
- Supabase URL وAnon Key للواجهة، وService Role Key للـ Backend فقط، أو تهيئة بديلة مكافئة.
- عقد Karam Pay الرسمي لمصادقة حساب التاجر، وعنوان webhook أو طريقة الاستعلام الرسمية والتوقيع. الواجهة العامة تؤكد إنشاء الدفع وفحص الحالة لكنها لا تثبت المصادقة أو webhook.
- Cloudflare R2 اختياري للصور. لا يلزم لإكمال تدفقات البيانات المحلية الحالية.

## تصميم الواجهة
نحافظ على RTL وCairo ولوحة الألوان الحالية، مع أسلوب Marketplace عملي: بطاقات بيضاء على خلفية دافئة، أخضر SOUQNA كلون ثقة، وذهبي للإجراءات المدفوعة. التفاعل يعطي حالات تحميل وفراغ وخطأ، ولا يعرض دفع المنتج عبر Karam Pay.

## بنية الملفات
- `src/`: واجهة React ومكونات buyer/merchant/admin.
- `src/services/`: repositories وpayment service المعزول عن مزود الدفع.
- `src/types/`: عقود البيانات والحالات.
- `server.ts`: API الخادم والتحقق من الدفع والتفعيل الآمن.
- `supabase/schema.sql`: جداول وقيود RLS قابلة للتطبيق بعد تهيئة Supabase.
- `public/manus-routes.json`: قائمة المسارات التي تعرضها الواجهة.
